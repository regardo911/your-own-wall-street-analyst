# Chapter 11: the weekly check

A two-minute check on a fixed day (Friday, say) that tells you whether the desk is still getting things right.

| File | What you do with it |
|---|---|
| [weekly-check.txt](weekly-check.txt) | The four moves: three random citations, one quiet name on EDGAR, one blind bear re-run, the log. |
| [error-log.txt](error-log.txt) | One row per miss, with its failure name. It lives in Research Desk as `error-log`. |
| [what-my-desk-sees.txt](what-my-desk-sees.txt) | The book's filled map, which "uses Equibles as the connector and a Gmail draft for the brief; yours will name your own". Redo every row for your setup. |

Slip an Apple tag into move 1 now and then: if it stops matching, your setup changed. Two misses with the same failure name point upstream: tighten the command, then change the source, then rerun Chapter 3's scorecard.

> One week's check has been run and logged: three citations opened, one quiet name checked on EDGAR, one blind re-run done, and any miss recorded in `error-log` with its failure name. Every item on your map is marked SENT or KEPT (or BLOCKED for order tools and a connector's portfolio tools).
