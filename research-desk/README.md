# Research Desk

The project from Chapter 3, in Appendix A's final form. Paste [`project-instructions.txt`](project-instructions.txt) into the instructions box, never into knowledge. Upload everything in [`knowledge/`](knowledge/), with your filled `thesis-cards`. All nine can go in on day one: a command sits idle until you type its name, and rule 8 makes `desk-memo AAPL` run the `desk-memo` file.
