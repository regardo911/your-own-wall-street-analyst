# Bear Desk

The second project, from Chapter 8. Create it in Claude as **Bear Desk**, paste [`project-instructions.txt`](project-instructions.txt) into its instructions, and upload [`knowledge/desk-bear.txt`](knowledge/desk-bear.txt).

The instructions are the bear's rules 1-5, then rule 8 from the Research Desk. Appendix A9 puts rule 8 in with them so that typing `desk-bear` runs the file.

What else goes in, what never does, and the test that proves the bear is blind: [chapter 8's folder](../chapters/08-the-bear/).
